파비콘 만들기 (favicon.ico 생성기)

로고 이미지 한 장으로 favicon.ico와 모든 크기의 사이트 아이콘을 만듭니다. 파일은 서버로 전송되지 않습니다.

여기를 클릭하거나 로고 이미지를 끌어다 놓으세요 PNG · JPG · WebP 지원 · 정사각형에 가까운 단순한 이미지 권장
이미지를 올리면 모든 크기의 아이콘이 자동으로 만들어집니다.

적용용 HTML 코드

내려받은 파일들을 사이트 최상위 경로에 올린 뒤, 아래 코드를 <head> 안에 붙여 넣으세요.

사용 방법

  1. 로고나 심볼 이미지를 올립니다. 정사각형이 아니면 가운데 기준으로 잘라서 만듭니다.
  2. 자동으로 생성된 favicon.ico(16·32·48px 포함)와 PNG 아이콘들을 내려받습니다.
  3. 파일을 웹사이트 최상위 경로에 올리고, 함께 제공되는 HTML 코드를 <head>에 붙여 넣습니다.

만들어지는 파일

파일용도
favicon.ico브라우저 탭·즐겨찾기 (16·32·48px이 한 파일에 포함)
apple-touch-icon.png (180px)아이폰·아이패드 홈 화면 추가
icon-192.png안드로이드 홈 화면, PWA
icon-512.pngPWA 설치 화면, 고해상도 표시

좋은 파비콘을 만드는 요령

파비콘은 최소 16×16px까지 줄어들기 때문에 단순할수록 좋습니다. 회사 로고 전체보다는 심볼만, 여러 글자보다는 한 글자가 잘 보입니다. 배경이 투명한 PNG를 올리면 투명도가 유지되며, 어두운 테마 브라우저에서도 잘 보이는지 확인하고 싶다면 너무 어두운 색은 피하는 것이 좋습니다.

로고가 정사각형이 아니라면 사진 자르기에서 1:1 비율로 먼저 잘라 원하는 부분이 정확히 들어가게 한 뒤 올리는 것을 추천합니다.

자주 묻는 질문

파비콘이 무엇인가요?

브라우저 탭, 즐겨찾기, 검색 결과 옆에 표시되는 웹사이트의 작은 아이콘입니다.

적용했는데 바로 안 보여요.

브라우저가 이전 아이콘을 기억(캐시)하고 있어서 그렇습니다. 강력 새로고침(Ctrl+Shift+R)을 하거나 시간이 지나면 새 아이콘이 표시됩니다.

올린 로고가 서버에 저장되나요?

아니요. 아이콘 생성은 전부 브라우저 안에서 이루어지며 이미지가 외부로 전송되지 않습니다.
