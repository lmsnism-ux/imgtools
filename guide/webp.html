WebP란? 웹사이트 이미지 최적화 완전 가이드

WebP는 구글이 개발한 최신 이미지 형식으로, 같은 화질에서 JPG보다 25~34% 용량이 작습니다. 웹사이트 속도 최적화에 관심이 있다면 반드시 알아야 할 형식입니다. WebP가 무엇인지, 언제 쓰면 좋은지 알아봅니다.

WebP의 핵심 특징

  • 작은 용량: 같은 화질 기준 JPG보다 25~34%, PNG보다 26% 용량이 작습니다.
  • 손실·무손실 모두 지원: JPG처럼 파일 크기를 줄이는 손실 압축과 PNG처럼 원본 그대로를 보존하는 무손실 압축을 모두 지원합니다.
  • 투명 배경 지원: PNG처럼 알파 채널(투명 배경)을 지원합니다.
  • 애니메이션 지원: GIF처럼 움직이는 이미지도 WebP 형식으로 만들 수 있습니다.

WebP가 유리한 상황

웹사이트·블로그 이미지: 페이지 로딩 속도에 직접 영향을 줍니다. 이미지 용량이 줄면 Core Web Vitals 점수(구글 SEO 평가 기준)가 높아지고 방문자 이탈률이 낮아집니다.

온라인 쇼핑몰 상품 사진: 상품 이미지 수십 장이 페이지에 올라가는 쇼핑몰에서는 WebP 전환만으로 페이지 로딩이 눈에 띄게 빨라집니다.

모바일 데이터 환경: 이미지 용량이 작을수록 데이터 절약이 되어 모바일 사용자에게 유리합니다.

WebP의 단점 — 이럴 때는 JPG·PNG를 써야 합니다

상황권장 형식이유
공공기관·기업 서류 제출JPGWebP를 지원하지 않는 시스템이 많음
구형 PC·소프트웨어에서 열기JPG 또는 PNGIE, 구형 포토샵 등 WebP 미지원
이메일 첨부 (수신자 환경 모름)JPGWebP를 못 여는 환경이 있을 수 있음
인쇄용 고품질 이미지PNG 또는 원본화질 손실 없는 형식이 더 적합

WebP로 변환하기

기존 JPG, PNG, HEIC 사진을 WebP로 변환하려면 이미지 형식 변환 도구를 사용하세요. 저장 형식을 WebP로 선택하고 파일을 올리면 됩니다. 설치나 회원가입 없이 브라우저에서 바로 변환되며, 파일이 서버로 전송되지 않습니다.

WebP 브라우저 지원 현황

크롬, 사파리(iOS 14+, macOS 11+), 파이어폭스, 엣지 등 현재 주요 브라우저 대부분이 WebP를 지원합니다. 2024년 기준 전 세계 브라우저의 96% 이상이 지원하므로 웹사이트 이미지로는 안심하고 사용할 수 있습니다. 다만 IE와 일부 구형 환경은 미지원입니다.

자주 묻는 질문

WebP가 JPG보다 항상 좋은 건가요?

용량 측면에서는 대부분 유리하지만, 범용성에서 JPG가 앞섭니다. 웹 환경이라면 WebP가 유리하고, 다양한 기기·프로그램에서 열어야 한다면 JPG가 안전합니다.

WebP를 JPG로 다시 변환할 수 있나요?

네. 이미지 형식 변환에서 WebP 파일을 올리고 JPG나 PNG를 선택하면 됩니다. 단, 손실 압축 WebP를 JPG로 변환하면 이미 줄어든 화질이 복원되지 않습니다.

워드프레스에서 이미지를 자동으로 WebP로 변환할 수 있나요?

EWWW Image Optimizer, Imagify 같은 플러그인을 사용하면 업로드 시 자동으로 WebP로 변환해줍니다. 서버 없이 HTML 사이트를 운영한다면 이미지를 미리 WebP로 변환해서 올리는 방법이 더 간단합니다.
